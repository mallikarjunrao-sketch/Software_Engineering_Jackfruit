5. UNCOVERED CODE ANALYSIS & RISK ASSESSMENT
--------------------------------------------------------------------------------
A total of 106 statements were not executed during the automated test suite. 
Each uncovered region has been investigated and assessed:

  1. backend/app/services/reports.py (74 Missed Statements)
     - Reason: This module contains optional manual interactive CLI reporting, 
       PDF document generation utilities, and standalone desktop report scripts.
     - Risk Assessment: LOW. The core operational dashboard data and daily CSV exports 
       are actively tested via backend/app/routers/dashboard.py and test_dashboard.py.
       System runtime operations do not depend on this CLI module.

  2. backend/app/routers/reports.py (10 Missed Statements)
     - Reason: Secondary administrative endpoints for legacy weekly/monthly archive 
       exports.
     - Risk Assessment: LOW. Core daily operational reporting is fully tested.

  3. backend/app/database.py (5 Missed Statements - lines 12, 35-39)
     - Reason: Fallback logic for external PostgreSQL / MySQL database drivers when 
       operating outside the standard SQLite production/testing profile.
     - Risk Assessment: ZERO. System runs on standard SQLite file engine in production.

  4. backend/app/main.py (4 Missed Statements - lines 31-34)
     - Reason: Direct script execution entry point (`if __name__ == '__main__': uvicorn.run(...)`).
     - Risk Assessment: ZERO. In production, FastAPI is invoked via ASGI server process 
       (Uvicorn/Gunicorn CLI), never via `python main.py` directly.

  5. backend/app/services/backup.py (4 Missed Statements - lines 46, 66-67, 74)
     - Reason: Rare operating system disk full error handling during file copy.
     - Risk Assessment: NEGLIGIBLE. Defensive exception handler.

  6. backend/app/routers/parking.py (3 Missed Statements - lines 117-119)
     - Reason: Catastrophic physical hardware barrier sensor disconnect exception.
     - Risk Assessment: NEGLIGIBLE. Defensive hardware fault trap.

  7. backend/app/routers/auth.py (2 Missed Statements - lines 59, 64)
     - Reason: Secondary attendant registration feature flag branch.
     - Risk Assessment: NEGLIGIBLE.
